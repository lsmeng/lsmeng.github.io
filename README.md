# Lingsen Meng — Academic Homepage

Static personal website: hand-written HTML, one `style.css`, small ES-module scripts, **no build step**.
Fonts (per design variant: Inter Tight + IBM Plex Sans, Space Grotesk + Inter + JetBrains Mono, or Instrument Sans + Inter) and libraries (Three.js, topojson-client, Natural Earth coastlines) load from
cdn.jsdelivr.net, which is reachable from mainland China; every page still works with system fonts.

## Layout
- `index.html` home (globe of the supershear survey), `research.html` research hub
- Topic pages: `rupture.html`, `back-projection.html`, `finite-fault.html`, `tsunami.html`, `swarms.html`,
  `ai-geoscience.html`; `data.html` lists every data file behind the figures.
  `source-imaging.html`, `eew.html`, `slow-slip.html` are redirect stubs to the merged pages.
- `publications.html` is generated by `python3 gen_pubs.py` (edit the list there).
- `assets/js/site.js` theme toggle, mobile menu, lazy loading of figures;
  `assets/js/viz/*.js` one module per interactive figure (data schema documented at the top of each file).
- `assets/data/` JSON/CSV/PNG read by the figures; `assets/icons.svg` line-icon sprite.

## Maintenance scripts (`tools/`)
- `python3 tools/site_chrome.py` stamps the shared head/nav/footer into every page (edit the menu there only).
- `python3 tools/build_site_data.py [SRC]` rebuilds `assets/data/` from the curated research data.
- `python3 tools/make_figures.py && python3 tools/inline_svg.py` redraws the matplotlib figures and inlines them.

## Preview locally

```bash
python3 -m http.server 8000
# open http://localhost:8000
```

## Deploy — GitHub + Cloudflare Pages (recommended, fast in China)

### 1. Put it on GitHub
```bash
git init
git add .
git commit -m "Initial site"
# create an empty repo on github.com first, then:
git branch -M main
git remote add origin https://github.com/<you>/<repo>.git
git push -u origin main
```

### 2. Connect Cloudflare Pages
1. Sign in at https://dash.cloudflare.com → **Workers & Pages** → **Create** → **Pages** → **Connect to Git**.
2. Pick this repo.
3. Build settings: **Framework preset = None**, **Build command = (leave empty)**,
   **Build output directory = `/`** (the repo root). It's a static site, so there is nothing to build.
4. **Save and Deploy**. You'll get a free `https://<project>.pages.dev` URL with global CDN
   (generally faster and more reliable from China than `github.io`).

Every `git push` to `main` re-deploys automatically.

### (Optional) Custom domain
In the Pages project → **Custom domains** → add e.g. `lingsenmeng.com`. If the domain's DNS is on
Cloudflare, this is one click and gives you HTTPS automatically.

## Alternative: GitHub Pages only
Repo **Settings → Pages → Source: Deploy from branch → `main` / root**. Site appears at
`https://<you>.github.io/<repo>/`. Works, but can be slow/intermittent in mainland China —
Cloudflare Pages is the better default.

## (Optional) Gitee mirror for China
For the most reliable access inside China, also push to [Gitee](https://gitee.com) and enable
Gitee Pages as a China-only entry point. Requires real-name verification.
